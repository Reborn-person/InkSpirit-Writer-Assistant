# 如何使用 1Panel 面板管理本项目

您提到的“青龙面板”主要用于脚本管理，而对于像本项目这样的全栈 Web 应用，**1Panel** 是目前最优秀的现代化服务器管理面板，完全符合您的需求。

好消息是：**您的项目中似乎已经保存了 1Panel 的登录信息**（请查看 `deploy/1panel-info.txt`）。

## 一、 如何在 1Panel 中部署本项目

1.  **登录面板**：
    *   打开浏览器访问您的 1Panel 地址（见 `deploy/1panel-info.txt`）。
    *   输入账号密码登录。

2.  **创建应用**：
    *   进入左侧菜单 **“容器”** -> **“编排”**。
    *   点击 **“创建编排”**。
    *   **名称**：输入 `ai-novel-writer`。
    *   **路径**：选择或输入项目所在的目录（例如 `/opt/1panel/apps/ai-novel-writer`，确保将项目代码上传到了这个目录）。
    *   **内容**：将 `deploy/docker-compose.yml` 的内容复制进去。
        *   *注意：如果您的代码在服务器上的路径结构不同，可能需要调整 `build: context: ..` 的路径，或者直接将 `docker-compose.yml` 放在项目根目录而不是 deploy 目录。*

3.  **启动**：
    *   点击“确认”或“创建”，面板会自动开始构建镜像并启动容器。

## 二、 如何进行“热更新” (Hot Update)

在 1Panel 中更新非常简单，无需输命令：

1.  **上传代码**：
    *   使用 1Panel 的 **“文件”** 管理功能，进入项目目录。
    *   上传覆盖最新的代码文件（或者如果配置了 Git，直接点击 Git 拉取）。

2.  **一键重建**：
    *   回到 **“容器”** -> **“编排”**。
    *   找到 `ai-novel-writer`。
    *   点击右侧的 **“更多”** -> **“重建”** (Rebuild)。
    *   勾选 **“拉取镜像/构建镜像”**（重要！这样才会使用新代码重新编译）。
    *   点击确认。

系统会在后台自动重新编译并重启，过程丝滑，即为“热更新”。

## 三、 其他便捷管理功能

*   **查看日志**：在编排列表中点击“日志”图标，可实时查看程序报错或运行状态。
*   **终端连接**：点击“终端”图标，可直接进入容器内部执行命令（如 `npx prisma db push`）。
*   **文件管理**：直接在线编辑 `deploy/.env` 或代码文件，保存即生效（前端代码需重建，后端代码部分需重启）。

---

**建议**：由于您已经有了 1Panel，强烈建议直接使用它来管理，比命令行的 `server_manage.sh` 更加直观和方便。
